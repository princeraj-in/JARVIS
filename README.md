# J.A.R.V.I.S. - Tri-Persona AI Desktop Assistant

Windows desktop assistant built with Python + PyQt6 + Gemini.
Personas: JARVIS, FRIDAY, ELEVEN. Voice, memory, Google Workspace, web/app automation.

## Setup
1. Python 3.12 recommended
2. `pip install -r requirements.txt`
3. Add your own Gemini API key(s) in Settings (BYOK)
4. `python jarvis.py`

## Build .exe
Run `build_exe.bat`

## Note
Google `credentials.json` is not included. Create your own in Google Cloud Console.
